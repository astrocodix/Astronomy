# أستروفرس أكاديمي — دليل البدء

**تعلّم الكون. افهم كل شيء.**

تطبيق تعليمي فعلي بالعربية والإنجليزية، مع دعم اتجاه الكتابة من اليمين إلى اليسار، وحفظ تفضيلات المظهر واللغة، والدروس والاختبارات والتقدم في قاعدة البيانات.

## ما الذي أُنجز؟

- خريطة كاملة من **12 مرحلة و146 وحدة**.
- المرحلة الأولى: **8 وحدات و16 درسًا ثنائي اللغة**، مع شرح متدرج وأمثلة وأنشطة ومصطلحات ومصادر وتقييمات.
- **864 سجل سؤال**، بواقع 108 لكل وحدة في المرحلة الأولى، مع 12 صيغة للإجابة. تتضمن الأعداد تنويعات للمفاهيم وليست 864 فكرة مستقلة خضعت لمراجعة علمية.
- اختبارات الدرس من 10 أو 20 أو 30 سؤالًا، واختبار الوحدة من 50، والمرحلة من 100، مع حفظ الإجابات المؤقتة واحتساب النتائج من الخادم.
- تقدم وإتقان وإنجازات وشهادات إتمام غير معتمدة، مستندة إلى بيانات المتعلم الفعلية لا إلى أرقام تجريبية مزيفة.
- مرصد تعليمي تفاعلي، ومكتبة، وصور علمية موثقة، ولوحة تحرير محمية بالصلاحيات.

**حدود النسخة:** المراحل من الثانية إلى الثانية عشرة خريطة تطوير وليست دروسًا مكتملة. ما زال محتوى النسخة التجريبية بانتظار مراجعة علمية ولغوية عربية مستقلة. المحاكاة تعليمية وليست خريطة سماء حية أو بيانات رصد لحظية.

## التشغيل المحلي

يُنصح باستخدام Node.js 22 LTS وnpm. لا تحتاج إلى مفتاح ذكاء اصطناعي لتجربة الدروس والاختبارات ودليل المراجع والصور المحلية.

```bash
npm ci
cp .env.example .env
```

عدّل ملف `.env` وحدد بريدًا وكلمة مرور قوية خاصة بك في `ADMIN_EMAIL` و`ADMIN_PASSWORD` لإنشاء حساب المسؤول. الحد الأدنى لكلمة المرور 12 محرفًا. **لا توجد كلمة مرور عامة افتراضية للمسؤول.** لا تنشر ملف الأسرار.

```bash
npm run setup
npm run dev
```

افتح `http://localhost:3000`.

- `/` لوحة المتعلم.
- `/welcome` التعريف بالأكاديمية.
- `/lesson/l-1-1` الدرس الأول.
- `/register` حفظ رحلة الضيف في حساب؛ لا يعيد التسجيل ضبط التقدم الحالي.
- `/login` تسجيل الدخول.
- `/admin` لوحة التحرير بعد الدخول بحساب مسؤول أو مدرّس.

لتشغيل نسخة البناء الإنتاجي:

```bash
npm run build
npm run start
```

قاعدة SQLite الافتراضية هي `prisma/academy.db`. يدعم المشروع PostgreSQL أيضًا بمخطط وترحيلات منفصلة. تغيير نوع القاعدة لا ينقل حساباتك ونتائجك تلقائيًا؛ راجع [دليل النشر](DEPLOYMENT.md).

## اللغة والمظهر

استخدم زر اللغة في الشريط العلوي لاختيار العربية أو الإنجليزية، وزر المظهر للتبديل بين الفاتح والداكن. تحفظ التفضيلات دون تغيير هوية المتعلم أو تقدمه. يمكن ضبط اللغة والمظهر والمنطقة الزمنية وهدف الدراسة من الإعدادات.

تبدأ الإحصاءات بصفر، ولا تصبح الدروس مكتملة لمجرد فتحها. اجتز تقييم الدرس ثم اختبار الوحدة لفتح المحتوى التالي عند تفعيل المتطلبات السابقة.

## المعلّم الذكي والبريد

لم يُربط مزوّد ذكاء اصطناعي مدفوع فعليًا في هذه النسخة المسلّمة. **دليل المراجع المتاح الآن يعمل فعليًا، لكنه بحث في مقتطفات دروس الأكاديمية وليس ردًا مولّدًا بالذكاء الاصطناعي.**

لتفعيل المزود، اضبط `OPENAI_API_KEY` و`AI_BASE_URL` على الخادم، وحدد النموذج والحصة في لوحة المسؤول. يستخدم النظام `AI_MODEL` و`AI_DAILY_LIMIT` فقط كقيم أولية عند تهيئة الإعدادات للمرة الأولى. اختبر المزود الحقيقي بالعربية والإنجليزية قبل الإعلان عن جاهزيته؛ نجحت اختبارات عقد التكامل مع مزود محاكى، لا مع خدمة مدفوعة حقيقية.

استعادة كلمة المرور تحتاج `RESEND_API_KEY` ومرسلًا موثقًا في `MAIL_FROM` ورابط التطبيق الصحيح في `APP_URL`. لم يُختبر تسليم بريد حقيقي هنا. لا يعرض النظام رسالة نجاح مزيفة إذا لم تُهيأ الخدمة.

## مراجعة المحتوى ونشره

`CONTENT_PREVIEW=true` يتيح المحتوى التجريبي المعلّم بأنه قيد المراجعة. للنشر العام استخدم `false` بعد مراجعة المحتوى واعتماده فعلًا. لن تظهر الدروس والأسئلة المعلقة في وضع النشر المراجع؛ وهذا سلوك مقصود، لا فقدان للبيانات.

يمكن تصدير محتوى أصلي دون تكلفة مزود:

```bash
npm run content:generate -- --export-seed --module m-1-1 --out drafts/module-1.json
npm run content:import -- --file drafts/module-1.json
```

الأمر الثاني فحص جاف لا يغير قاعدة البيانات. الاستيراد الفعلي يحتاج `--apply` وبريد محرر موجود، وينشئ مسودات جديدة فقط. لا تنشر مخرجات الذكاء الاصطناعي دون التحقق من العلم والوحدات والإجابات والترجمة والمصادر والحقوق. راجع [دليل المحتوى والمراجعة](CONTENT.md).

## الاختبارات والنسخ الاحتياطي

```bash
npm test
npm run content:validate
npm run db:backup
```

اختبارات المتصفح تحتاج خادمًا وقاعدة اختبار منفصلين؛ **لا تشغّلها على قاعدة المتعلمين الحقيقية**. التعليمات والتقارير في [دليل الاختبارات](TESTING.md).

يحفظ النسخ الاحتياطي قاعدة البيانات، لكن يجب أيضًا نسخ `storage/uploads/` وحماية الأسرار وإجراء تجربة استعادة مستقلة. الصور والخطوط لها حقوقها الخاصة، ولا يعني وجود شعار جهة في بيانات المصدر أنها تعتمد التطبيق أو أجوبة المعلّم.
